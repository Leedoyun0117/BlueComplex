# DLJ 침체·흥분 화면 연출

기준: [Notion UI 연출](https://app.notion.com/p/UI-3e2f2999e1d7809fa7e0c39b9b94c1ea). BGM 처리 없음.

## 실행

`Assets/Scenes/DLJ/DLJ_GameTestScene.unity`에 `DLJ Heartbeat Mood Effects` 오브젝트를 연결해 둠.
Unity에서 외부 수정된 씬을 Reload하거나 다시 열고 Play한 뒤, 해당 오브젝트의 인스펙터 버튼으로 미리보기 가능.
미리보기는 실제 심박수, 단서, 게임 결과를 변경하지 않음. `실제 상태 복귀`로 게임 연동을 재개.

다른 PC 렌더러 사용 씬에는 `Tools > BlueComplex > DLJ > Setup Mood Effects In Active Scene` 실행 후 씬 저장.
같은 CRT 렌더러를 공유하는 컨트롤러는 하나만 활성화. 모바일 렌더러에는 별도 CRT Feature 연결이 필요.

## 동작

### 방별 연결 / 방 3 창문 산란

`DLJ Heartbeat Mood Effects`를 선택하면 Inspector의 `Rooms` 목록에 Hierarchy 오브젝트를 끌어 넣을 수 있음.
DLJ 테스트 씬에는 3개 항목을 저장했고 기존 연결은 방 1로 이동. 방 3에 현재 테스트 씬의 창문 연결을 옮겼고 `Window Edges` 모드를 적용. 방 2는 미연결 상태.
다른 기존 씬은 인스펙터의 `기존 연결을 방 1로 옮기고 방 2·3 목록 만들기` 버튼으로 변환 가능.
목록을 만들지 않은 기존 씬은 이전 직렬화 필드 그대로 동작. 원래 연출의 수치는 변환 시 변경하지 않음.

`Rooms > 각 방 > 연출 설정`에서 해당 방의 침체·흥분·전환 수치와 창문 스타일 설정을 독립적으로 편집.
색상, 광선 강도/굵기/속도/감쇠, 파스텔 팔레트, 색수차·글리치 지속 시간 등을 모두 방별로 저장.
기존 DLJ 테스트 씬의 조정값을 세 방에 각각 복사했으며, 한 방을 수정해도 다른 방의 값은 변경되지 않음.
다른 기존 씬은 인스펙터를 열거나 처음 실행할 때 이전 값을 한 번만 복사. 이미 편집한 방은 다시 덮어쓰지 않음.
방 목록이 있으면 이전 공통 수치는 인스펙터에서 숨기며, 방 목록이 없는 씬만 기존 공통 수치를 사용.
`Active Room Index`로 미리볼 방을 선택. Play 중 활성 방의 색/광선 수치를 바꾸면 바로 적용되고, Play 중 변경값은 일반 Unity 동작처럼 종료 시 원복됨.
색수차·글리치 전체 지속 시간은 다음 흥분 진입부터 적용. 방을 바꿔도 진행 중인 진입 타이머를 재시작하지 않음.
현재 감정 강도와 전환 시간은 선택한 방의 설정에 맞게 갱신. CRT 연결과 기본 프리셋만 컨트롤러에서 공통 사용.

방 3에는 중앙 광선 없이 창문 바깥 둘레의 빛만 남기는 `Window Style = Window Glow` 적용.
`Fine Rays`는 이전 광선 그대로 유지하며, 방 1·2의 저장값과 기존 셰이더 경로는 변경하지 않음.
스타일은 현재 방이 `Window Edges` 모드일 때만 활성화되고, 다른 방으로 전환하면 매 프레임 해당 방 설정으로 갱신.
`Room Shafts`는 네 변에서 바깥으로 나뉜 굵은 빛줄기를 만들고, 모서리에서는 대각선으로 펼친다. 창문 안쪽은 광선 합성에서 제외. 변마다 줄기 수와 묶음 위치가 다르고, 폭·밝기·길이도 줄기마다 달라짐. 빛의 세기는 약하게 일렁임.
`Center Shafts`는 창문 네 변의 평균 중심을 출발점으로 삼고, 각 줄기가 창틀의 다른 지점을 통과해 바깥으로 뻗는다. 광선 폭과 주변 확산 범위를 좁혀 배경을 덮지 않으며, 기존 `Room Shafts`도 스타일 목록에 남아 있음.
`Window Glow`는 광선을 그리지 않고 창틀 가까이에만 옅은 확산광을 만든다. 창문 안쪽과 UI에는 빛을 합성하지 않음. Center Shafts는 비교를 위해 스타일 목록에 남아 있음.
모서리의 대각선 광선과 변의 첫 줄기 사이에는 짧게 감쇠하는 부드러운 빛을 넣어 검은 쐐기 모양 틈을 메움. 창틀 경계 안쪽 몇 픽셀도 부드럽게 덮되 창문 중앙은 제외. 두 변에서 중복으로 과하게 밝아지지 않도록 가장 강한 모서리 빛만 사용.
방 3 조정값: 창문 `Length=0.66`, `Strength=0.65`; `Window Band Opacity=0.3`, `Window Shaft Ambient Strength=0.28`, `Window Band Tint=(0.9, 0.92, 0.96)`. 광선 폭·중심 밝기·묶음·위아래 길이 값은 저장되지만 Window Glow에서는 사용하지 않음.
`Window Shaft Grouping=0.75`로 몇 줄기씩 느슨하게 묶음. `Window Shaft Vertical Bias`는 출발점 높이와 아래쪽 밝기 차이를 조절하며, 방 3 저장값은 0.6.
`Window Shaft Top Length=0.18`, `Window Shaft Bottom Length=0.85`는 창틀 바깥으로 더 뻗는 위·아래 광선 길이를 각각 조절. 중앙 출발 스타일에서는 중심에서 창틀까지의 거리도 자동으로 더함. 좌우 광선은 창문 항목의 `Length=0.66`을 사용. 각 값은 방별로 따로 저장.
Window Glow의 확산 반경은 창틀 근처로 제한하며 네 변에 같은 폭을 적용. 위쪽 광선 길이가 짧아도 위쪽과 왼쪽 위 모서리의 주변광이 좁아지지 않음. `Window Shaft Ambient Strength=0.28`은 주변광 자체의 세기이고 `Window Band Opacity=0.3`은 전체 표시량. 너무 밝으면 둘 중 하나를 낮추면 됨.
방 3의 `Water Width Variation=0.9`로 줄기별 폭 차이를 조금 더 키움.
`Water Fade Start=0.3`, `Water Distance Fade=0.85`로 빛이 방 안쪽까지 이어지게 함. 파란 침체 색감과 흥분 설정은 기존 방 3 값 유지.
`Soft Bands`는 이전 창문 둘레 빛 띠 스타일로 남아 있음. 창틀 바깥 방향과 모서리 연결을 유지하고, 기울어진 시작면의 검은 잘림은 창틀 선에서 메움.
`Window Band Opacity`는 Soft Bands, Room Shafts, Center Shafts, Window Glow의 전체 투명도(0=투명, 1=불투명)를 조절. `Window Band Core Brightness`는 광선 스타일 세 종류의 중심 밝기만 조절하며 Window Glow에는 적용하지 않음. Fine Rays/전구에도 적용하지 않음.

1. `Rooms > 방 3`에서 `Scene Camera`에 해당 방의 배경 카메라, `Lights`에 침체 중 흰색으로 바꿀 광원을 연결.
2. `Active Room Index`를 `2`로 설정. 0=방 1, 1=방 2, 2=방 3.
3. `선택한 방에 창문 테두리 지점 만들기` 버튼으로 모서리 4개를 생성.
4. 생성된 `DLJ 방 3 Window Outline`의 모서리 지점을 Scene 뷰에서 실제 창틀 테두리에 맞춤.
   생성 위치는 화면 우측 상단의 편집용 기본 위치이며 실제 창문을 자동 인식한 위치가 아님.
   창문 레이어가 움직이면 생성한 그룹을 그 레이어의 자식으로 옮겨 함께 움직이게 설정.
5. Play 후 `침체 55` / `매우 침체 25`로 확인.

`Windows`는 창문별 목록, `Corners`는 테두리를 따라 순서대로 연결하는 Transform 목록.
사각형은 좌상→우상→우하→좌하처럼 연결. 마지막 점을 첫 점으로 중복 등록할 필요 없음.
`Closed`를 끄면 마지막 변을 닫지 않으며, 점 2개로 창살 하나도 표현 가능.
창문 빛은 각 테두리의 바깥 방향으로만 산란: 위 변은 위, 아래 변은 아래, 좌우 변은 각각 좌우로 펼쳐짐.
모서리를 순서대로 연결한 윤곽에서 바깥 법선을 계산하므로 창문이 기울거나 모서리 순서를 반대로 등록해도 방향을 유지.
각 변 중앙은 바깥 법선을 중심으로, 양 끝은 모서리 쪽으로 약 55도까지 펼쳐 이웃 변과 대각선에서 이어짐. 모서리 근처의 출발점 밀도를 높여 대각선 빈틈을 줄임.
기본 방향 주변의 작은 각도 편차(약 ±3.4도), 느린 방향 흔들림, 얕은 휨과 길이 편차(설정 길이의 52~100%)로 반듯한 빗살 느낌을 완화. 빛은 계속 바깥쪽으로만 진행.
심·주변 산란·잔광 모두 해당 테두리의 바깥쪽에만 표시. 기존 `Interior Target`/`Direction` 연결은 보존하지만 사용하지 않으며 인스펙터에서 숨김.
점 2개만 사용하는 열린 선은 안팎을 판단할 윤곽이 없으므로 화면 텍스처 좌표에서 등록한 진행 방향의 오른쪽을 바깥으로 사용. 반대쪽이 필요하면 두 점 순서를 뒤집음.
창문마다 `Length`(화면 높이 기준 길이), `Strength`(세기), `Edge Width`(시작부 폭) 조절 가능.
창문 출발점은 실제 테두리를 따르고, 창틀 바깥으로 뻗는 흰 심·청록 산란·끝 잔광을 기존 파란 색감에 합성.
어두운 창틀도 지정 가능하도록 창문 산란은 밝기 추출에 의존하지 않음. `Strength=0`으로 해당 창문 산란을 끔.
기존 전구 광선의 회전과 원뿔을 복제하지 않고, 창문 변에 고정된 출발점에서 바깥쪽으로 빛줄기를 펼침. 밝기·작은 각도·얕은 휨이 천천히 변화하고, 안쪽 픽셀은 광선 반복 전에 제외.
`Water Beam Count`는 창문 변당 8~48개 광선, 방당 최대 8개 변. 창문 모드에는 전구의 넓은 각도 자동 수량 보강을 적용하지 않음.
`Water Afterglow Angle/Length`, `Water Scatter Angle`, `Water Source Radius/Light Spread/Direction`은 전구용이며 창문 길이·폭은 창문 항목에서 조절.
파란 색감, 빛줄기 굵기·거리 감쇠·일렁임, 흥분 진입 및 유지 연출은 선택한 방의 `연출 설정` 사용.

방 전환 스크립트/UnityEvent에서는 `SelectRoom(0/1/2)` 호출. 이 API는 연출 연결과 수치를 변경하고 배경 오브젝트의 활성화는 변경하지 않음.
이전 방 광원 색/색온도 사용 여부를 복원한 뒤 선택한 방만 처리. 방 전환 때문에 흥분 진입 타이머를 재시작하지 않음.
`Root`는 선택 사항이며 비활성화하면 해당 방의 광원/산란도 해제. 자동 방 선택 기능은 아니므로 전환 시 인덱스를 지정해야 함.
목록의 광원/전구가 비어 있으면 다른 방에서 자동 수집하지 않음. 카메라가 없으면 산란을 끔.
각 참조는 컨트롤러와 같은 씬의 오브젝트를 사용. 별도 씬마다 컨트롤러를 설정하되 같은 CRT Feature를 쓰는 컨트롤러는 하나만 활성화.
창문 산란은 화면 공간 연출이며 깊이 기반 가림/실제 물리 광선은 아님. UI에는 산란을 덮지 않음.
화면을 가로지르는 창문 변은 부분 클리핑하며, 카메라 근거리/원거리 클립 평면을 가로지르는 변은 제외.
`Tools > BlueComplex > DLJ > Validate Mood Room Bindings`로 광원 복원·방 분리·빈 연결·창문 경계 검사를 재실행 가능.

- 71~100: 기본 CRT 유지, 추가 상태 효과 없음.
- 40~70: 선명한 파란 색감, 흰 Point/Spot 광원, 밝은 배경에서 내려오는 가는 수중 빛줄기 유지.
- 10~39: 침체 효과 강도 증가.
- 101~150: 진입 색수차 총 3.5초. 마지막 1초 동안 잔상·일렁임을 감쇠하며 파스텔 핑크 단색 톤으로 전환 후 유지. 가로 글리치는 기존처럼 2초.
- 151~190: 진입 색수차 강도 증가. 같은 흥분 계열 내 이동은 색수차·글리치 타이머를 재시작하지 않음.
- 안정/침체로 이동하면 색수차·글리치를 즉시 중단하고 지속 색감을 0.65초에 걸쳐 전환.
- 극단 구간은 해당 방향의 최대 효과 유지. 별도 사망 연출을 추가하지 않음.
- 초기 바인딩·세션 재시작·실제 상태 복귀는 즉시 동기화하며 진입 색수차·글리치를 재생하지 않음. 흥분 상태면 핑크 톤으로 바로 복귀.

기획에서 재발동 조건과 매우 침체/매우 흥분의 강도는 지정하지 않아 위 규칙을 구현 기본값으로 선택.
일반 구간 강도 0.75, 극단 구간 강도 1.0. 인스펙터에서 색·번짐·색수차·글리치 시간을 조절 가능.

침체는 노션의 강한 파랑/어두운 실루엣과 가는 청백색 광선을 기준으로 조정.
둥근 블룸은 최대 침체에서 기본의 20%로 줄이고, 참고 이미지처럼 여러 겹의 긴 청백색 광선을 적용.
배경에만 제한된 1픽셀 샤프닝과 대비 1.3을 적용하며 UI 글자는 해당 처리에서 제외.
`Depressed Contrast/Sharpness`로 대비·윤곽을, `Water Light Sharpness`로 광선 폭을 조절.
`Water Light Spread`는 광선 길이(기본 0.28, 화면 높이 기준)이며 폭이 아님.
전구 폭에서 출발하는 기본 24개 광선의 간격·굵기·길이를 서로 다르게 하고, 흰 중심과 청록색 외곽 산란을 겹침.
참고 이미지의 길고 불규칙한 빛줄기를 코드로 근사. 채워진 삼각형, 일정한 간격의 줄무늬, 동일한 길이의 끝선을 제거.
아주 가는 줄 / 중간 줄 / 넓은 빛 띠의 세 부류로 나누고 광선 끝은 개별 길이에 따라 부드럽게 사라짐.
굵기 계수는 가는 줄 0.1~0.32, 중간 줄 0.7~1.2, 넓은 띠 2.3~4.5로 분리(최소 폭 제한은 별도).
광선은 곧은 중심선과 고정된 굵기를 유지하며, 끝으로 갈수록 폭이 선형으로 조금 넓어짐.
머리카락처럼 휘어지는 위치 변화와 물결 모양의 굵기 변화는 제거. 각 줄의 밝기만 서로 다른 속도로 천천히 변함.
`Water Beam Count`: 전등당 기본 수량 24개(8~48). 각도 22도 초과 시 자동 보강하며 120도에서 기본 24개 → 49개.
보강 시 홀수 수량으로 중앙 광선을 보장하고, 중앙 쪽 배치 밀도와 외곽 번짐 폭을 늘려 빈 공간을 줄임.
최대 97개/전등. 수량 증가 시 밝기를 보정하며 GPU 연산량은 증가. 흰 중심선은 계속 직선 유지.
`Water Width Variation`: 줄 사이의 굵기 편차, 기본 1. 0이면 기본 굵기가 같아짐.
`Water Wave Strength`: 밝기 일렁임 강도, 기본 1. 0이면 밝기의 시간 변화를 중단. 위치/굵기에는 영향 없음.
`Water Wave Speed`: 밝기 일렁임 속도, 기본 0.8. 0이면 시간 0의 밝기로 고정.
`Water Light Direction`은 방향 각도: 0=아래, 90=오른쪽, -90=왼쪽, ±180=위. 코어와 외곽이 함께 회전.
`Water Scatter Angle`은 전체 벌어짐 각도: 기본 22도(참고 이미지형), 0도(평행), 120도(넓은 묶음).
최신 참고 이미지 요청에 맞춰 테스트 씬의 기존 120도를 22도로 변경. 필요하면 인스펙터에서 120으로 조절.
`Water Scatter Strength`(기본 1.15)는 청록색 외곽 산란 강도. 0이어도 흰 코어는 유지.
각도와 길이는 가로세로 비율을 보정한 배럴 왜곡 전 화면 공간 기준. 방향을 돌려도 빛줄기가 찌그러지지 않음.
전구 주변 밝기만 5탭으로 추출하고 UI에는 빛을 덮지 않음. 광원이 없거나 어두우면 광선을 생성하지 않음.
현재 CRT 입력의 아래쪽(-UV Y)을 방향 0으로 사용. 렌더 패스/입력 텍스처 방향 변경 시 재검증 필요.
밝기만으로 광원을 판정하지 않도록 `Scatter Lights`에 지정한 전등의 화면 위치 주변만 추출.
DLJ 테스트 씬은 `Lamp Point Light`만 연결하여 위쪽 막대/책상 테두리의 가짜 산란을 제외.
목록이 비어 있으면 기존 광원 목록의 Point Light만 사용하며, 유효한 전등/카메라가 없으면 산란 없음.
`Scene Camera`는 배경 카메라, `Water Source Radius`는 발광부를 포함하는 반경(기본 0.035).
광원 위치가 전구 이미지에서 벗어나거나 반경 안에 다른 밝은 물체가 겹치면 별도 조정 필요.
광원 반경 마스크는 물체별 발광 마스크나 깊이 기반 가림을 대체하지 않음.
실제 물리 산란/반사나 깊이 기반 가림이 아닌 화면 공간 근사이며, 화면 밖 광원은 산란에 기여하지 않음.

진입 파스텔 색감은 노션 첫 번째 흥분 이미지에 맞춰 연분홍·민트·라벤더 잔상을 혼합.
원색 RGB 채널 분리 대신 이동한 실루엣에 팔레트 색을 입히고, 덧셈 대신 가중 혼합으로 흰색 날림을 줄임.
진입 중 채도 0.58/대비 0.84를 강도에 따라 적용. 색수차 종료 후 원래 명암과 부드러운 대비를 살린 핑크 단색 톤 유지.
지속 중에는 민트·라벤더 잔상, 화면 일렁임, 기본 CRT의 RGB 색수차가 남지 않도록 처리.
`Chromatic Seconds`는 감쇠 포함 전체 시간(기본 3.5초), `Chromatic Fade Seconds`는 마지막 감쇠 구간(기본 1초).
시간을 0으로 설정하면 바로 핑크 톤 적용. 안정/침체를 거쳐 재진입할 때만 진입 연출 재생.
`Pastel Pink/Mint/Lavender`, `Pastel Saturation/Contrast/Grade Strength`로 조절 가능.
